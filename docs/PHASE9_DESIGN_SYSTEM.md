# 用度 · 阶段九设计规范

本规范服务微信小程序「用度」首页高保真样板，并作为记账、账单、设置三页后续铺开的视觉基线。
阶段九只改首页样板与本文档；业务数据、领域算法与路由保持不变。

## 1. 品牌气质与禁区

**气质**

- 温暖、克制、现代，有“活人感”：像一本随身小账本，而不是银行 App。
- 语气安静、直接：先说“今天还能花多少”，再说周期与细节。
- 主色偏赤陶暖红，背景偏米杏；深色只用于金额主卡，避免大面积纯黑。

**禁区**

- 卡通插画、贴纸风、拟物金币堆砌。
- 传统纹样、水墨装饰、节庆红包感。
- 借贷/催收感：刺眼大红、倒计时恐吓、债务标签化文案。
- 互联网大促感：渐变霓虹、满屏折扣色、跳动动效。
- 外部字体、图标库、组件库、图片资源、新 npm 依赖。

对比度目标：普通文字 ≥ 4.5:1；大号金额字（深底浅字或浅底深字）≥ 3:1。

**实测对比度（WCAG 相对亮度，sRGB）**

| 前景 | 背景 | 约对比度 |
|------|------|----------|
| `#796D63` | `#F7F4EF` | ≈4.58:1 |
| `#796D63` | `#FFFDFA` | ≈4.95:1 |
| `#FFFDFA` | `#B45842` | ≈4.68:1 |

**首页局部覆盖说明**

- 弱文字与主按钮色值只在 `home.wxss` 覆盖（`.home-page .eyebrow` / `.hint` / 弱标题与 `.primary-button`），**不修改** `app.wxss`，避免另三页未经确认换色。
- 深色主卡次文 `#C7BDB1` 保持不变。

## 3. 字体层级

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| 页面标题 | 48rpx | 600 | 1.3 | “今天，慢一点花” |
| 主金额 | 80rpx（≤320px 用 64rpx） | 600 | 1.15 | 今日可自由花 |
| 区块标题 | 24–26rpx | 500–600 | 1.4 | 卡片 eyebrow/标题；`.card-kicker` 固定 24rpx |
| 正文 | 28rpx | 400 | 1.6 | 列表主文 |
| 说明 | 24–26rpx | 400 | 1.6 | 周期、hint、空状态 |
| 最小正文 | **24rpx** | — | ≥1.5 | 首页不得更小 |

字体栈：系统默认（`-apple-system, BlinkMacSystemFont, "Helvetica Neue", sans-serif`），不引入 Web 字体。

## 4. 间距、圆角、边框、阴影

- **间距基准**：4 / 8 倍数。页面左右 32rpx（≤320px 用 24rpx）；区块间距 16–32rpx；卡片内边距 28–40rpx。
- **圆角**：主卡 28rpx；次卡 22rpx；按钮 16rpx；轻提示 18rpx。
- **边框**：1rpx 浅暖灰；结算卡可用同色细边提示“需处理”。
- **阴影**：主卡可用 `0 12rpx 36rpx rgba(66, 52, 39, 0.08)`；次卡可无阴影，靠边框与底色分层。避免厚重投影。

## 5. 组件层级

1. **主按钮**：唯一强烈 CTA（首页＝记一笔）。高 ≥ 88rpx，主色 `#B45842` 实底，字 `#FFFDFA`。
2. **次按钮**：账单分析、设置、重试入账等。高 ≥ 88rpx，浅暖底，深棕字。
3. **轻链接按钮**：关闭逾期等。透明底，主色字，不与主 CTA 抢视线。
4. **资产入口**：描边/浅色处理，可达但不抢主 CTA。
5. **卡片**：承载结算、额度、计划；无事件时计划区降低对比。
6. **表单行**：标签左/上 + 输入右；主要可点区域高度 ≥ 88rpx。
7. **提示 / 错误 / 空状态**：提示偏暖橙；错误偏红但不刺眼；空状态弱文字 + 真实下一步（去设置页）。

## 6. 适配与排版规则

- **常规宽度**：纵向 flex；`.home-actions` 使用 `margin-top: auto` 消化大屏剩余空间，使主操作靠近内容区底部；不靠假卡片、放大留白或写死高度填屏；不使用 fixed/sticky 遮挡内容。
- **320px**：主金额缩小一级；横向 `flex` 改为纵向；金额与长文 `overflow-wrap: anywhere`；禁止横向溢出、遮挡、截断主操作；内容超高时操作区保持文档流，可滚动进入安全区。
- **安全区**：页面底部 `padding-bottom: calc(64rpx + env(safe-area-inset-bottom))`（继承全局）。
- **长金额 / 长文案**：任意处可断行；状态行允许纵排；不得 `white-space: nowrap` 锁死金额。

## 7. 首页六种状态

| 状态 | 表现 | 一级焦点 |
|------|------|----------|
| 正常 | 深色主卡展示 `todayFree`；二级展示完整单日额度与周期 | 今日可自由花 |
| 预支恢复 | 二级条显示已预支与预计恢复日/额 | 今日可自由花仍居中 |
| 待结算 | 主卡替换为结算卡；必须选择结余/超支处理 | 结算确认 |
| 计划提醒 | 有提醒/今日到期时计划区提高对比；无事件时弱化 | 仍不压过主金额 |
| 待处理 | 独立待处理卡 + 补金额/重试 | 待处理可操作 |
| 错误 | 顶部错误条，正文对比清晰 | 错误可读且不挡主 CTA |

## 8. 后续三页复用与首页特例

**可全局复用**

- 色板、字号阶梯、8 倍数间距、88rpx 点击高、安全区、小屏纵排、暖色按钮体系。
- 卡片边框/圆角、错误条、空状态文案语气。

**首页特例（勿强行全局化）**

- 深色超大金额主卡与 “YONGDU / TODAY” eyebrow。
- “记一笔”作为唯一主 CTA 的独占权重与 `#B45842` 局部主色。
- 计划区“无事件极简 / 有事件抬升”的双态；其他页可按列表密度处理。
- 结算态整卡替换主金额区的结构。
- 大屏操作区 `margin-top: auto` 下沉。

## 9. 验收口径（半自动）

- 自动化：绑定与可达性契约、WCAG 对比度计算、字号下限、文档章节齐全、小屏与点击尺寸规则存在。
- 人工：Stable 上 iPhone 12/13 与 iPhone 5（320px）真实截图；风格是否通过由领导确认，执行者不得自称视觉已获认可。
