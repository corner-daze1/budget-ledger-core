# 第七阶段：本地数据安全规格

## 范围与不变量

- 本阶段只把现有 `schemaVersion: 1` 账本接到微信本地文件能力，不新增云端、登录、网络、权限、加密或第三方依赖。
- JSON 完整备份包含账户、流水、预算周期、计划、待确认项和设置；所有金额仍为整数分，币种只允许 CNY。
- CSV 沿用领域层既有固定列，仅供查看和分析，不能用于恢复。
- 导出、预检、取消恢复和取消清除不得改变当前账本。恢复成功前，页面内存状态不得切换。

## 决策表

| 动作 | 前置条件 | 写入范围 | 成功结果 | 失败结果 |
| --- | --- | --- | --- | --- |
| 导出 JSON | 已初始化；序列化后不超过 5 MiB | 小程序用户目录中的 `yongdu-backup-本地时间.json` | 显示文件名、大小，可由用户主动分享或复制文本 | 明确中文错误；当前账本不变 |
| 导出 CSV | 已初始化；序列化后不超过 5 MiB | 小程序用户目录中的 `yongdu-transactions-本地时间.csv` | 显示文件名、大小和“不能恢复”提示 | 明确中文错误；当前账本不变 |
| 选择备份 | 用户主动调用 `wx.chooseMessageFile` 且只选一个 JSON | 无 | 文件读取前、读取后各检查 5 MiB | 取消不报假错误；格式或大小错误明确展示 |
| 粘贴备份 | 用户主动粘贴 JSON 文本 | 无 | 进入同一预检流程 | 不读取系统剪贴板，不扫描设备 |
| 预检 | JSON 可解析、版本可迁移、CNY、结构与引用合法 | 无 | 显示名称、大小、源/目标 schema、币种、五类数量、最近流水日期；无可靠生成时间时显示“未知” | 返回错误及原始文本，不清空、不覆盖 |
| 恢复 | 预检成功；输入“恢复”；最终弹窗确认 | 只写主键 `yongdu-ledger-v1` 和临时键 `yongdu-ledger-v1-restore-temp` | 临时写读校验、主键写读校验、清临时键全部成功后才替换页面状态 | 任一步失败均尝试回滚原主键并清临时键；不运行到期计划 |
| 清除 | 输入“清除”；最终弹窗确认 | 只删主键、临时键和本应用生成的两类文件 | 页面回到未初始化状态 | 不调用 `clearStorage`，不碰其他键或目录 |
| 分享/复制 | 用户明确点击 | 只处理刚生成文件或其文本 | 调用平台能力 | 不支持时提示并提供“手动复制”按钮；绝不自动复制、上传或分享 |

## 原子恢复顺序

1. 保存原主键原文。
2. 候选账本规范化后写临时键，立即读回、解析并逐字节规范化校验。
3. 写主键，立即读回、解析并逐字节规范化校验。
4. 删除临时键。
5. 只有以上全部成功，调用方才能把候选账本设为页面状态。
6. 任一步失败，恢复原主键（原本不存在则删除主键），校验回滚结果，并清理临时键；回滚和清理各允许一次重试，错误必须显式返回。

版本 0 没有应用设置字段时，沿用既有领域迁移并补入确定性的首版默认值：周期起始日 1、默认预算等于迁移后的 `defaultBudgetCents`。版本 1 缺少设置字段视为损坏，不猜测或补写。

## 精确删除与隐私

- 生成文件只允许匹配 `yongdu-backup-*.json` 或 `yongdu-transactions-*.csv`，并且必须位于 `wx.env.USER_DATA_PATH`。
- 不读取剪贴板、不扫描通讯录/相册/其他目录，不自动触发分享，不上传任何账本。
- 设置页固定分为五个独立区块：完整备份、恢复预览、CSV 账单、危险操作、隐私说明。
- 数据默认仅存在本机，不上传、不用于 AI；只有用户主动导出、分享或复制时才离开小程序。
- JSON 备份与 CSV 是未加密明文，可能包含敏感财务信息，分享前由用户自行确认接收方和存放位置。
- 卸载小程序、清理微信缓存或设备故障可能导致丢失；清除后如果没有 JSON 备份，数据无法恢复。
- 本阶段没有云同步、账号恢复或加密承诺。以上是产品说明，不代表已完成平台法律合规。

## 验收要点

- 新测试至少 28 项，覆盖大小双检、损坏 JSON、版本/币种、重复标识、引用完整性、预览摘要、取消零写入、恢复成功、各写读删失败回滚、精确清除、JSON/CSV 文件名与内容。
- 反向验证必须临时破坏“主键写入失败仍保留原数据”的测试，先取得红灯，再恢复并全绿。
- 稳定版开发者工具只执行非破坏性路径：真实生成文件；打开文件选择后取消；进入恢复/清除最终确认后取消。
