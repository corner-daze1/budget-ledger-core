# 阶段十：用度首页第二版与底部导航规范

## 目标与边界

本阶段只交付首页第二版高保真样板和全局底部导航。预算、账单、资产、计划、恢复和存储模型不改；完整账单、我的、记账三页的内容布局不重绘，只做与 Tab 页跳转兼容的最小调整。

导航参考当前 TDesign 微信小程序 TabBar 的公开契约：固定底部、底部安全区、受控选中值、change 事件、占位高度和轻量图标。项目不安装组件库，导航由本地 custom-tab-bar 实现，以保持包体和自动取证稳定。

参考：

- https://tdesign.tencent.com/miniprogram/components/tab-bar
- https://github.com/Tencent/tdesign-miniprogram/tree/main/packages/components/tab-bar
- https://github.com/Tencent/tdesign-miniprogram/blob/main/packages/components/tab-bar/tab-bar.ts
- https://github.com/Tencent/tdesign-miniprogram/blob/main/packages/components/tab-bar/tab-bar.less

## 视觉令牌

| 用途 | 令牌 | 规则 |
| --- | --- | --- |
| 页面底色 | `#F6F5F0` | 温和的暖灰，不使用纯黑背景 |
| 卡片底色 | `#FFFFFF` | 与页面底色形成轻层次 |
| 正文 | `#202521` | 金额、标题和主要字段 |
| 设计参考的次文色 | `#737871` | 仅用于弱层次装饰或非正文参考色 |
| 正文可读次文色 | `#5F665F` | 页面实际次要文字，保证在 `#F6F5F0` 上对比度 ≥4.5:1 |
| 品牌松绿 | `#3E725E` | 选中态、导航动作和主要强调 |
| 品牌浅底 | `#E8F0EB` | 选中背景、提示底色和轻量标签 |
| 预支/错误 | `#B85A4A` | 只表达风险、预支、错误，不作大面积主背景 |
| 描边 | `#E5E7E2` | 分隔线、输入框和卡片边界 |

`#737871` 与页面底色的实测对比度为 4.13:1，不满足普通文字的 4.5:1 要求，因此正文实际使用更深的 `#5F665F`；这是为满足可访问性对领导选定参考色的最小调整，已记录在 `PROGRESS.md`。

## 字号、间距与形状

- 页面标题：40–44rpx，字重 600，行高 1.3；不使用英文装饰眉题。
- 主金额：72rpx 左右，字重 600，允许长金额换行，不压缩或截断真实数据。
- 区块标题：28–32rpx，正文：28rpx，次文：24–26rpx，导航文字：22rpx。
- 间距只使用 8/12/16/24/32rpx 的节奏；卡片内边距 24–32rpx。
- 普通卡片圆角 20–24rpx；按钮和输入框圆角 14–16rpx；导航动作使用圆形。
- 阴影只用于中央动作或极轻的卡片层次：低透明度、低扩散，不制造悬浮金融面板。
- 所有可点击的导航项、按钮、链接和中央动作最小点击高度为 88rpx。
- 普通文字、按钮文字和选中/未选中导航文字对比度均至少 4.5:1；装饰线不作为信息唯一载体。

## 首页层级

1. 中文页头：只保留“用度”和一句解释，不再放首页重复的“我的”入口。
2. 今日可自由花主卡：金额是第一视觉焦点，继续绑定 `model.todayFree`。
3. 单日基准和刻度：刻度只表达相对单日基准的状态，不伪装成月预算百分比。
4. 动态解释：积攒、预支恢复日、待结算、起始日待生效等只在真实状态出现。
5. 账本面板：概览态在预算下方露出按可用空间容纳的最近完整流水行；展开后沿用同一列表连续浏览全部流水，不按数量截断。
6. 逾期提醒、计划摘要、待处理和错误：只在真实发生时出现，保留原有业务动作和文案含义。

首页不再放大号“记一笔”主按钮，也不放重复的“我的”链接；这两个入口分别由底部中央动作和“我的”Tab 承担。结算确认按钮属于结算流程，不属于普通记账 CTA，必须保留。

## 首页账本停靠契约

- 首页只有 `overview`（预算概览态）和 `expanded`（全屏账本态）两个停靠状态，不保留任意中间高度或半展开状态。
- 概览态账单面板使用固定可用空间高度，流水数量增加不改变面板停靠高度；显示多少完整行由屏幕可用空间自然决定，不写死三笔或五笔。
- 手指上推超过阈值后直接进入 `expanded`；展开态账本面板接管滚动，预算概览不占滚动内容。只有列表 `scrollTop=0` 时向下拉才回到 `overview`；短滑、取消和快速滑动不得留下中间状态。
- 展开态顶部固定显示“账本”和“分析”；“分析”仍使用现有 bills 页面入口，底部“账本｜记一笔｜我的”保持固定。
- 流水由 `core.listRecentTransactions` 提供，按日期倒序分组，同日保持现有倒序；日汇总分开展示支出和收入，转账、还款、借贷、投资不计入消费汇总，退款按发生日冲减支出。
- 首次进入为概览态；记账成功返回只消费一次性首页重置信号并回到概览；分析返回、切换“我的”再回来保留状态与位置；重复点击已选中的“账本”Tab 调用首页公开重置并滚到最新日期。

## 底部导航契约

| 位置 | 文案 | 路径 | 行为 | 选中规则 |
| --- | --- | --- | --- | --- |
| 左 | 账本 | `/pages/home/home` | `wx.switchTab` | 当前路由为 home |
| 中央动作 | 记一笔 | `/pages/entry/entry` | `wx.navigateTo` | 不参与 tab 选中 |
| 右 | 我的 | `/pages/settings/settings` | `wx.switchTab` | 当前路由为 settings |

- `app.json` 的 tab 列表只有账本/home与我的/settings两个目的地；完整账单与分析页 bills 保留为非 Tab 页面，中央“记一笔”也不是 tab 项。
- 已初始化用户冷启动默认从 `/pages/home/home`（账本）进入。
- 首次没有账本时仍由 `home.onShow` 使用 `wx.switchTab('/pages/settings/settings')` 跳转到“我的”完成设置。
- custom-tab-bar 每次显示都从 `getCurrentPages()` 读取当前路由，不能把上一次点击的 tab 当作选中态。
- bills与entry都不是 tab 页，二者不出现选中态；记账页保持专注模式，不显示底部导航。
- 左右两个 tab 使用 `switchTab`；账本页“全部”账单入口使用 `navigateTo('/pages/bills/bills')`，返回后仍在账本。
- 账本页点击“记一笔”直接 `navigateTo`；我的页先 `switchTab('/pages/home/home')`，成功后再 `navigateTo('/pages/entry/entry')`，保证返回落到账本。
- 首页、账单或记账发现没有账本时，使用 `switchTab` 进入我的页；首次设置、恢复成功后使用 `switchTab` 回账本；清除后使用 `switchTab` 回我的页。
- 导航固定在底部，使用安全区 padding；页面内容底部预留导航高度加安全区，最后一行不可被遮挡。
- 图标使用本地 CSS 线性图形，不读取网络资源，不依赖组件包或外部字体。

## 状态与禁区

必须保留：今日可自由花、单日基准、积攒、预支恢复日、待结算、逾期、待处理、错误、全部账本流水、日期分组、收入/支出日汇总和空状态。

禁止：黑色金融主卡、荧光色、英文装饰眉题、卡片层层嵌套、卡通化、传统纹样堆砌、月预算百分比假进度、隐藏元素冒充交付、网络图标、修改预算/资产/账单/存储业务代码。

## 小屏验收

- 在 320px 宽度下页面横向不溢出；长分类、金额和错误信息可以换行。
- 导航三个点击区均不少于 88rpx，中央动作不能覆盖相邻 tab 的点击区。
- 页面底部 padding 足以容纳导航主体和 `env(safe-area-inset-bottom)`；账本列表最后一行仍可完整阅读和点击。
- 视觉取证 fixture 必须分别证明概览态与展开态的完整内容和安全区导航；记账页不要求显示导航。
