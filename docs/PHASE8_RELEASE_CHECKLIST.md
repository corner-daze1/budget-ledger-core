# 参赛版发布检查清单

本清单用于参赛版本的非破坏验收。除特别注明外，失败或取消后都必须保留原账户余额、预算周期、计划、流水、恢复预览和用户尚未提交的输入。

## 1. 首次设置

- 入口：无本地账本时进入设置页。
- 成功反馈：完成预算、起始日和至少一个现金类账户后进入首页。
- 空状态：初始账户表单直接展开，并说明可继续添加账户。
- 失败保持：非法金额、日期或账户输入不得创建半份账本，原表单输入保留。

## 2. 支出、收入与转账

- 入口：底部中央“记一笔”动作，在三种模式间切换；它不是 Tab。
- 成功反馈：保存后回首页；再次进入同类支出可看到上一笔同类。
- 空状态：没有可用账户时说明先到设置页添加账户。
- 失败保持：余额不足、账户缺失或非法金额不得新增流水或改变账户、预算。

## 3. 预算结算

- 入口：首页遇到已结束周期时显示结算卡。
- 成功反馈：用户明确选择结余/超支处理方式后进入下一周期。
- 空状态：没有需要处理的结余或超支时不制造选择项。
- 失败保持：取消或非法选择不得关闭旧周期、创建新周期或改写历史。

## 4. 资产、债务与投资

- 入口：设置页“资产账户”分区。
- 成功反馈：账户新增、还款、借贷、利息、投资买卖或估值后在分区内提示。
- 空状态：没有账户时说明在本分区添加第一个账户。
- 失败保持：余额/欠款不足、账户类型不匹配或非法金额不得产生半笔交易。

## 5. 计划提醒与待处理

- 入口：设置页“计划提醒”分区；首页显示到期、提醒和待处理。
- 成功反馈：计划创建、编辑、停用或待处理重试后就近提示。
- 空状态：没有计划时说明可在当前分区创建；没有提醒时说明可到设置页配置。
- 失败保持：金额未定、余额不足或账户失效只保留一条待处理，不改账面余额和预算。

## 6. 两种分析口径

- 入口：账本页“全部”进入完整账单与分析，切换“可控支出/全部支出”。
- 成功反馈：每日、分类和周期趋势及文字兜底随口径更新。
- 退款在原消费日期重述净支出，退款日期不产生负支出点；已关闭周期只重述分析，不改结算值。
- 空状态：没有账单或周期时说明先记录一笔，不填充演示数据。
- 失败保持：切换和绘图失败不得修改流水、预算周期或账户余额。

## 7. 修改、退款与撤销

- 入口：点击账单进入只读详情；在首页完整账本或账单分析页左滑，按“退款｜修改｜撤销”进入对应模式。
- 成功反馈：提交前展示账户、预算和奖励影响；成功后列表只显示最新有效版本，并保留原账、冲正、新版本或退款的审计关系。
- 退款边界：可分次退款，累计不得超过剩余可退金额；默认退回原账户，也允许选择实际到账账户。
- 失败保持：余额不足、日期越界、没有覆盖操作日的开放预算周期、重复请求或保存读回失败，都不得留下半状态。
- 已结算边界：不重算历史结算值；历史多扣进入奖励，历史少扣由覆盖操作日的开放预算周期承担。

## 8. 备份、恢复与清除

- 入口：设置页“数据与隐私”分区，选择 JSON 或手工粘贴后预检。
- 成功反馈：仅显示文件元数据、版本与数量摘要，明确“尚未写入”。
- 空状态：未选择文件时提示先选择或粘贴 JSON。
- 失败保持：损坏、超限或不兼容备份不得写存储；取消恢复保留当前账本和预览。
- 真实账本只执行导出、预检和最终确认前取消。发布前另用独立隔离账本完成一次 schema v2 恢复、清除和无关键保留验证。
- 微信缺失存储键可能读回空字符串；清除成功校验必须使用统一缺键语义，不得因此误报失败或恢复已删除数据。
- 清除分为两个一致性域：确认后先清除主键和恢复临时键；账本删除、读回或校验失败时精确回滚两键并跳过文件清理。
- 账本清除成功后立即进入未初始化状态，再删除严格匹配的本应用 JSON/CSV；文件删除失败不回滚账本，并原样显示“账本已清除，但部分导出文件未删除，请稍后重试清理。”

## 9. 关闭并重开持久化

- 入口：完成非破坏查看后关闭项目，再从 Stable 项目管理器重开。
- 成功反馈：预算、账户、流水、计划和分析口径仍由本地数据正确呈现。
- 空状态：首次使用仍回到设置表单，不伪造历史数据。
- 失败保持：损坏存储显示明确错误并保留原始数据，不静默清空。
