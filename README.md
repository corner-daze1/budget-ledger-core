# 记账小程序财务内核

这是首版离线财务内核：原生 JavaScript、整数分、CNY，产品运行时不依赖第三方包。预算计算、账户流水、信用卡与借贷、投资形态转换、奖励余额、固定计划、版本化备份校验和 CSV 导出都在 `src/domain/` 中以可组合函数提供。开发期仅使用精确锁定的 `miniprogram-automator@0.12.1` 做本地自动视觉取证。

运行：

```text
npm test
npm run check
npm run build:mini
npm run check:mini
```

微信开发者工具 Stable 已安装且保持登录会话时，可运行：

```text
npm run evidence:visual -- --compat
npm run evidence:visual
```

视觉取证只使用 `.visual-qa` 隔离副本和 `touristappid`，不会读取测试 AppID 的账本。完整机制、产物和失败规则见 `docs/VISUAL_EVIDENCE.md`。

## 设计边界

`src/domain/` 不接触微信运行时、DOM、网络、文件系统、进程环境或密钥。当前小程序界面只负责把表单输入转换成应用层参数、展示返回值和选择备份文件；金额、周期、结转、退款和账户余额仍由领域函数决定。云端若在后续版本接入，只能保存版本化 JSON、鉴权和处理同步冲突，不能直接覆盖本地流水或静默丢弃损坏数据。

当前参赛版已提供动态累计预算、六类账户、计划与小程序内提醒、三张分析图、账单修改/退款/撤销审计闭环、`schemaVersion: 2` JSON 完整备份与恢复预检，以及只导出最新有效用户记录的 CSV。首版仍不包含 AI分析、云同步、行情、汇率、会员和后台定时通知。导出的 CSV 仅供查看，不是可逆备份；完整恢复必须使用 JSON 备份。

## 小程序应用边界

`miniprogram/` 是原生微信小程序壳，页面只通过 `src/application/app-core.js` 使用已验证的领域能力；应用层不接网络或 AI。当前固定五页依次为账本、我的（设置与资产）、统一“支出/收入/转账”入口、账单分析和唯一非Tab账单详情页，数据通过微信本地存储保存版本化 JSON。底部视觉导航为“账本｜记一笔｜我的”，其中只有账本和我的是 Tab，中央“记一笔”是动作入口；完整账单从账本页“全部”进入。已初始化用户默认进入账本，首次无账本时自动转到我的完成设置。初始化后的我的页使用“预算与周期、计划提醒、资产账户、数据与隐私”四个互斥折叠分区。

第三阶段支持现金、储蓄卡、电子钱包、信用卡、借贷和投资六类账户，以及信用卡还款、借款、归还本金、利息支付、投资买卖和手工估值。所有金额仍是整数分；信用卡支出按性质扣预算，收入、互转、还款、借贷、还本、利息和投资操作不会冒充可控支出。详细规则见 `docs/PHASE3_ASSET_SPEC.md`。

计划只在小程序启动或回到前台时检查，提醒显示在小程序内；它不是后台定时通知。账单分析提供每日净支出、一级分类占比和最近六个真实预算周期趋势三张图，并保留普通文字兜底。界面可以继续迭代，但不能绕过应用层复制预算公式。

## 本地数据管理

设置页的数据管理区可以把完整账本导出为 `schemaVersion: 2` 的 JSON，也可以把最新有效、用户可读的固定列账单导出为 CSV。恢复只接受当前 `schemaVersion: 2`，旧版本不会迁移；JSON 可经预检和两次人工确认后原子恢复，CSV 只供查看、不能恢复。文件写在微信小程序用户目录，只有用户主动点击时才分享或复制，不会自动上传、读取剪贴板或扫描设备。

恢复会先校验 5 MiB 上限、JSON、版本、CNY、结构、重复标识和流水引用，再经过临时键与主键的写后读校验。任何失败都会尝试保留原主键并清理临时键；恢复成功后也不会顺带执行到期计划。清除分两个一致性域：先只处理本应用主键和恢复临时键，账本删除、读回或校验失败时精确回滚且不删除文件；账本成功后立即进入未初始化状态，再删除严格匹配的本应用 JSON/CSV，文件清理失败不回滚账本并显示“账本已清除，但部分导出文件未删除，请稍后重试清理。”不调用全局清空。Stable 缺键读回空字符串、空白字符串及其他无效值按不同语义处理，详见 `docs/PHASE7_DATA_SAFETY_SPEC.md`。

数据默认仅存在本机，不上传、不用于 AI；只有用户主动导出、分享或复制时才离开小程序。卸载小程序、清理微信缓存或设备故障可能造成数据丢失，请定期保存 JSON 完整备份。备份和 CSV 是未加密明文，可能含有敏感财务信息，分享前请确认接收方和存放位置。清除后如果没有 JSON 备份，数据无法恢复。本阶段没有云同步、账号找回、网络上传或加密承诺；以上是产品说明，不代表已完成平台法律合规。详细规则见 `docs/PHASE7_DATA_SAFETY_SPEC.md`。
