# 记账小程序财务内核

这是首版离线财务内核：原生 JavaScript、整数分、CNY、无第三方依赖。预算计算、账户流水、信用卡与借贷、投资形态转换、奖励余额、固定计划、版本化备份迁移和 CSV 导出都在 `src/domain/` 中以可组合函数提供。

运行：

```text
npm test
npm run check
npm run build:mini
npm run check:mini
```

## 设计边界

`src/domain/` 不接触微信运行时、DOM、网络、文件系统、进程环境或密钥。小程序界面未来只负责把表单输入转换成领域函数参数、展示返回值和选择备份文件；金额、周期、结转、退款和账户余额仍由领域函数决定。云端未来只负责保存版本化 JSON、鉴权和同步冲突界面，不能直接覆盖本地流水，也不能静默丢弃损坏数据；同步策略必须保留历史交易并在冲突时显式返回待处理结果。

本版不提供 AI 分类、行情、汇率、预测、语音、图表或真实提醒。导出的 CSV 是账单交换格式，不是可逆备份；完整恢复必须使用 JSON 备份。

## 小程序应用边界

`miniprogram/` 是原生微信小程序壳，页面只通过 `src/application/app-core.js` 使用已验证的领域能力；应用层不接网络、文件系统或 AI。当前固定四页覆盖首页、资产中心、统一“支出/收入/转账”入口和最近流水，数据通过微信本地存储保存版本化 JSON。设置页在首次启动时负责预算与初始现金类账户，初始化后复用为资产中心。

第三阶段支持现金、储蓄卡、电子钱包、信用卡、借贷和投资六类账户，以及信用卡还款、借款、归还本金、利息支付、投资买卖和手工估值。所有金额仍是整数分；信用卡支出按性质扣预算，收入、互转、还款、借贷、还本、利息和投资操作不会冒充可控支出。详细规则见 `docs/PHASE3_ASSET_SPEC.md`。

未来云端只能保存版本化备份、鉴权并返回显式同步冲突，不能静默覆盖本地流水、改写历史余额或把云端响应直接当作账本事实。未来 UI 可替换表单和展示层，但不能绕过应用层复制预算公式。

## 本地数据管理

设置页的数据管理区可以把完整账本导出为 `schemaVersion: 1` 的 JSON，也可以把固定列账单导出为 CSV。JSON 可经预检和两次人工确认后原子恢复；CSV 只供查看，不能恢复。文件写在微信小程序用户目录，只有用户主动点击时才分享或复制，不会自动上传、读取剪贴板或扫描设备。

恢复会先校验 5 MiB 上限、JSON、版本、CNY、结构、重复标识和流水引用，再经过临时键与主键的写后读校验。任何失败都会尝试保留原主键并清理临时键；恢复成功后也不会顺带执行到期计划。清除只处理本应用主键、恢复临时键和本应用生成的 JSON/CSV 文件，不调用全局清空。

数据默认仅存在本机，不上传、不用于 AI；只有用户主动导出、分享或复制时才离开小程序。卸载小程序、清理微信缓存或设备故障可能造成数据丢失，请定期保存 JSON 完整备份。备份和 CSV 是未加密明文，可能含有敏感财务信息，分享前请确认接收方和存放位置。清除后如果没有 JSON 备份，数据无法恢复。本阶段没有云同步、账号找回、网络上传或加密承诺；以上是产品说明，不代表已完成平台法律合规。详细规则见 `docs/PHASE7_DATA_SAFETY_SPEC.md`。
